Clicking the calendar or pressing F4 takes this path. Create the popup from an async command and exercise it on Windows.
2. **High — A Windows upgrade can replace a working 0.4.5 with an app that cannot launch.** `installer/offwork.iss:137` installs only the EXE. The custom Inno route bypasses Tauri’s WebView2 bootstrap. On a machine without the runtime the silent upgrade closes the working native widget, replaces it, and cannot display the replacement. Check or install WebView2 before replacing the old EXE.
3. **High — Linux update staging can overwrite an unrelated file.** `rust/src-tauri/src/updater.rs:228` copies the verified payload to a predictable sibling with overwrite semantics. An existing file there is truncated, and a symlink in a shared install directory redirects the write and chmod to its target. Stage in an exclusively created file alongside the installed image.
4. **High — Starting an update blanks the widget.** `rust/src/App.svelte:242` sends the unit-returning `start_update` through a helper expecting a View. On success `show(null)` clears the view before throwing. The clock and earnings disappear, and subsequent progress and error events are ignored. The Wayland inline calendar finish at line 121 has the same return-type mismatch.
5. **Medium — OCR and manual edits can overwrite each other.** `rust/src-tauri/src/main.rs:79` snapshots all settings before the separate persist call. A salary edit committed between those operations is silently reverted by OCR, changing displayed earnings and the value saved for the next launch. Make the read-modify-save one serialized operation.
6. **Medium — Migration can skip the actual 0.4.5 settings.** `rust/core/src/store.rs:336` uses the process environment while C++ uses the Windows known folder. A launcher overriding LOCALAPPDATA imports from the wrong directory and the first save makes those defaults authoritative there. When the variable is absent, the WINDIR fallback is calculated but never read because `rust/src-tauri/src/main.rs:139` skips import. Resolve the legacy path using the same Win32 rule.
7. **Medium — AppImage restart races the single-instance lock.** `rust/src-tauri/src/updater.rs:233` starts the replacement before asking the old process to exit at line 316. If the new process reaches the singleton first, it hands control back to the exiting process and the user has to relaunch manually.
